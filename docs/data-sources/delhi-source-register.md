## Source conflicts and publication rule

The Delhi Assembly site has a [Members of Parliament from Delhi](https://delhiassembly.delhi.gov.in/dlas/members-parliament-delhi) page listing members from an earlier Lok Sabha despite a recent update footer. It must not be treated as a current MP roster. Use current Sansad evidence and review each appointment. A snapshot failure preserves the prior reviewed value with a stale label; it never deletes an incumbent. The expected count is unknown unless the source states it, so coverage must say partial or unknown rather than complete.
