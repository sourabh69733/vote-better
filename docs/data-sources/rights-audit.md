## Gate for new sources

Before an automated adapter is enabled, record the exact source URL, site owner, policy URL and check date, allowed collection method, rate limit, retention rule, public-display rule, required attribution, and whether permission is needed. A missing or ambiguous permission is **not** an approval. Link to the original record while its reuse status is unresolved. The present Sansad directory is a provisional user-directed exception to the earlier local-only display decision, not a finding that reuse is permitted.

Public pages must distinguish source claims from independent verification and show capture dates. Private snapshots must never be served directly. A site's `robots.txt` is an access signal, not a content license.
