# Jaipur profile comprehension check

Use this after the site can be shown to Jaipur residents. The study has not yet been run.

Show the homepage and the Manju Sharma profile on a phone. Do not explain the page first. Ask each person to:

1. Find who represents Jaipur in the Lok Sabha and name the source for that claim.
2. Explain what the renewable-energy question proves, and what it does not prove.
3. Find the 2024 election result in the original return of election.
4. Identify at least one topic the profile does not yet cover.
5. Say whether the page told them how to vote.

Record where they tapped, where they hesitated, their answer in their own words, and whether the source link opened. Test in Hindi and English before expanding the profile. A correct answer should distinguish a documented parliamentary action from a delivered public outcome.
